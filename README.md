# CBSE Study Hub V3 — Premium

A polished, static Class 10 CBSE 2026–27 study dashboard for GitHub Pages.

## Features
- Premium responsive dashboard
- Syllabus tracker with subject filters and search
- Personal notes stored in localStorage
- Revision queue with spaced-revision scheduling
- Analytics and subject progress
- Official CBSE resource links
- Mobile sidebar
- Theme toggle
- No backend or login required

## Deploy
Upload `index.html` and `README.md` to the root of your existing GitHub Pages repository and replace the old `index.html`.

Official CBSE resources are linked externally; the site does not copy CBSE documents.
